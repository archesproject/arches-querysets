## Arches Querysets 1.1.0 Release Notes

### Enhancements

- Performance improvements for geospatial indexing: `after_update_all` for GeoJSON geometries is now non-blocking when eventually consistent indexing is enabled [#148](https://github.com/archesproject/arches-querysets/pull/148)
- Save operations now return blank tile data instead of omitting blank values [#149](https://github.com/archesproject/arches-querysets/pull/149)
- Harden various save/delete patterns for reliability [#153](https://github.com/archesproject/arches-querysets/pull/153)
- Tile deletes now use the core Arches `Tile.delete()` method, ensuring graph functions are invoked [#170](https://github.com/archesproject/arches-querysets/pull/170)
- Resource deletes now use the core Arches model delete method via `ResourceTileTree` [#177](https://github.com/archesproject/arches-querysets/pull/177)

### Bug Fixes

- Fix blank resource tile fill [#143](https://github.com/archesproject/arches-querysets/pull/143)
- Fix nested cardinality-n POST duplication issue [#144](https://github.com/archesproject/arches-querysets/pull/144)
- Fix nested cardinality-n tiles not performing a clean delete [#152](https://github.com/archesproject/arches-querysets/pull/152)
- Fix custom path resolution in the bulk uploader [#154](https://github.com/archesproject/arches-querysets/pull/154)
- Fix naming change in core Arches that broke bulk imports [#156](https://github.com/archesproject/arches-querysets/pull/156)
- Fix version number comparisons [#171](https://github.com/archesproject/arches-querysets/pull/171)
- Fix tile reordering [#174](https://github.com/archesproject/arches-querysets/pull/174)
