# Arches Querysets 1.3.0 Release Notes

## Installation or Upgrade

Requires Arches 7.6.12+ or 8.1.0+ (excludes 8.0.0).

```shell
pip install 'arches-querysets==1.3.0'
```

Or with the optional Django REST Framework integration:

```shell
pip install 'arches-querysets[drf]==1.3.0'
```

To upgrade from a previous version:

```shell
pip install --upgrade 'arches-querysets==1.3.0'
```
