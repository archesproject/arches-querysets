# Arches Querysets 1.3.0 Release Notes

## Installation or Upgrade

Requires Arches 8.2.0+

```shell
pip install 'arches-querysets==1.3.0'
```

Or with the optional Django REST Framework integration:

```shell
pip install 'arches-querysets[drf]==1.3.0'
```

To upgrade from a previous version:

```shell
pip install --upgrade 'arches-querysets==1.3.0'
```

### New Features

- Retrieves default node values from node config rather than CardsXNodesXWidgets in accordance with Arches 8.2

### Performance Improvements

- Improves performance of the geojson-feature-collection datatype [#206](https://github.com/archesproject/arches-querysets/pull/206)

### Bug Fixes

- Fix handling of missing languages in related resources. [#182](https://github.com/archesproject/arches-querysets/pull/182)

### Breaking Changes

- Arches 8.2.0 is now the minimum Arches version
