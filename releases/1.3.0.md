# Arches Querysets 1.3.0 Release Notes

## Installation or Upgrade

Requires Arches 7.6.12+ or 8.1.0+ (excludes 8.0.0).

```shell
pip install 'arches-querysets==1.3.0'
```

Or with the optional Django REST Framework integration:

```shell
pip install 'arches-querysets[drf]==1.3.0'
```

To upgrade from a previous version:

```shell
pip install --upgrade 'arches-querysets==1.3.0'
```

### New Features

- `get_tiles(nodes=...)` now scopes per-tile decoding to just the requested nodes instead of every node in the nodegroup. Tiles returned by such a call have no `aliased_data` attribute for an unlisted node. [#218](https://github.com/archesproject/arches-querysets/pull/218)
- Provisional edit overlay: pass `provisional_edits_for_user` to `get_tiles()`, `save()`, or `refresh_from_db()` to surface pending edits in `aliased_data` for the edit author or a Resource Reviewer, without affecting the authoritative record. Enable it on a DRF view by setting `provisional_edits = True` on your `ArchesModelAPIMixin` subclass. [#224](https://github.com/archesproject/arches-querysets/pull/224)

### Performance Improvements

- Improves performance of the geojson-feature-collection datatype [#206](https://github.com/archesproject/arches-querysets/pull/206)
