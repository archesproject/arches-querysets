## Arches Querysets 1.1.2 Release Notes

### Installation or Upgrade

Requires Arches 7.6.12+ or 8.1.x (excludes 8.0.0).

```shell
pip install 'arches-querysets==1.1.2'
```

Or with the optional Django REST Framework integration:

```shell
pip install 'arches-querysets[drf]==1.1.2'
```

To upgrade from a previous version:

```shell
pip install --upgrade 'arches-querysets==1.1.2'
```
